# 2D techniques - the anime MV feel

toki 2026-10-22: keep 3D for flexibility, but it must read like her 2D reference MVs (Usseewa, Idol, LUVORATORRRRRY,
BRING IT ON, 39 Music!, ...); 10-25: "es sieht noch sehr flach und cartoon-mäßig aus ... nicht so plastik-artig".
Flat + plastic is NOT the 2D feel; graphic + designed is. Sources: knowledge/craft/04, studies/anime_techniques.md,
references `yoasobi-idol`, `ado-usseewa`, `ado-show`, `csm-op`, `edgerunners-this-fffire`, `zzz-come-alive`,
`zutomayo-study-me`, `kanaria-requiem`.

## 1. The toolbox (open list - add what the references show)
- **Timing**: on twos / threes for the body, full rate for camera and FX; stepped held keys; the fewest poses that
  sell an action (Arc System Works: 10 -> 6 -> 3).
- **Smears and multiples**: stretched solid shapes, multiple limbs, motion arcs drawn as shapes on fast moves.
- **Impact frames**: 1-3 frames of inverted / two-tone / black-and-white high contrast on a hit; often with a flash
  and screen shake.
- **Speed lines / focus lines** (radial on a reveal, parallel on a dash), **sakuga** bursts, **anime glints**.
- **Graphic shots**: two-colour states for two emotions (Usseewa blue / red), a single symbolic object in a void (Idol
  heart), the character as a repeated pattern, giant vertical type as a wall, split screens, comic panels, frames
  inside frames.
- **Extreme crops**: eyes only, lips, hands, a shoe, hair edges - fragments carry rhythm.
- **Light as graphic**: posterised 2-3 tone light, hard terminator, rim light as a line, colour holds (red flash),
  halftone / screentone used sparingly.
- **2D FX on 3D**: hand-drawn-looking smoke, fire, sparkles, water splashes as animated textures; outlines; paper /
  grain texture over everything for one material.
- **Camera in 2D**: multiplane parallax, push on stills with layers, snap zooms, shake, rotation on beats.

## 2. Making 3D read as 2D (Raymi VRM)
Cel shading with a hard terminator and coloured shadows (never grey), no GI bounce, outlines, held poses, body on
twos, perspective cheats per shot, matte surfaces (never glossy plastic), 2D FX layers on top, colour per section.

## 3. Judging
- Would a frame grab look like a designed anime still (composition, value pattern) - or like a game screenshot?
- Is there at least one graphic idea per section (not only "her in a room")?
- Plastic check: specular highlights, smooth gradients everywhere, grey shading -> fail.
- Next to the reference frame (`refs pair`): same energy and graphic boldness?
