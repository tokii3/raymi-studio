# Reading toki - intent, not words

Why this skill exists (2026-10-25): for a month her examples were built literally and her core got lost ("lerne über
alle farben also rot, blau etc -> du lernst nur rot und blau"; Watch Me: "eine einzelne Kamerafahrt" vanished from the
treatment, "sie flirtet mit der Kamera" became move functions, the FIRESTARTER reference became a menu of 10 codes).
She writes fast and short ON PURPOSE: "ich kann nicht immer jedes einzelne Wort schreiben, deshalb muss ich abkürzen und
Beispiele geben." Abbreviation is trust that I fill the gaps with thinking, not with the easiest version.

## 1. The protocol (every brief / every piece of feedback)

1. **Quote her core** - the 1-3 phrases that carry the feeling, verbatim (German). Not my paraphrase.
2. **Name the GOAL behind it** - what should a viewer feel / do? Why does she want it (her taste, the channel, a
   reference she loved)? Look up related verdicts: `jobs/*/toki.md`, memory `user-toki`, CASEBOOK.
3. **Open every example into its class.** Each example is ONE member of a set. Write the set and at least 5 more
   members she did not name. "rot, blau etc" -> all colours, plus what colour is FOR (mood, contrast, temperature).
   "vogueing / jojo posing" -> extreme silhouettes held as a shape: also K-pop killing parts, fashion editorial,
   anime transformation poses, Sailor Moon, idol finger hearts, fighting-game win poses.
   A reference clip -> its FEELING and principles for the whole video, plus where it is literal.
3b. **Find the conflicts.** Where two of her messages pull apart ("nur an 1 Ort" vs "bitte alle Ideen verwenden"),
   write it as `- X1 "<A>" vs "<B>" -> my guess: ... -> ASK` and ask her before planning further. Never resolve it
   silently - in Watch Me the silent guess (three worlds) killed "one place, one ride". `raymi next` holds the job
   until `answered X1: toki YYYY-MM-DD ...` is in the brief.
4. **Make it visible.** For each core phrase: "in the finished video you can SEE this when ..." - a test a stranger
   could answer from the real frames / the real video (not from our plan). This is the brief contract.
5. **Feasibility.** For each core phrase: which clip / asset / tool makes it real? If one is missing, SAY IT NOW
   ("das Herz deines Videos geht mit unseren Clips nicht, so lösen wir es: ..."), never build around it.
6. **Restate to her in 2-3 sentences** (her core + the class + the hardest part) when the work is big. Then build.

## 2. The brief contract (file `jobs/<job>/0_BRIEF.md`, written before the dossier)

```
## Her words (verbatim, dated)            <- copied, never edited
## Core (her phrases)                       <- 1-3 lines
## Goal behind it                           <- why, for whom
## Classes (example -> the whole set)       <- every example opened up
## Visible proof (each must be TRUE in the finished video)
- [ ] C1 "<her phrase>" -> <what a stranger sees in the frames / video> -> checked by <brief-keeper | reality | both>
## Feasibility (each proof: how it is built, what is missing)
## References (catalog refs / her links + the moment in them)
```
Every later step quotes the contract's C-lines: treatment, script, every board (top line = her core), every render.
The `brief-keeper` agent judges against THIS file + the real result - never against my treatment.

## 3. Feedback and verdicts

- Her words verbatim into `toki.md` FIRST (`<step>: toki YYYY-MM-DD "<words>"`), the same turn.
- Repeated feedback = the process failed. Find the earlier statement (grep toki.md, memory), name the fault CLASS,
  change the skill / agent / check that owns it, update memory - same turn (memory `learning-is-a-mechanism`).
- Re-read the ORIGINAL brief contract after every verdict: is the whole goal still there, or did the fixes eat it?
  ("immer wird das gesamt Ziel aus den Augen verloren").
- Never swing to the opposite extreme; compare with the last two things she liked.
- "sieht schon gut aus" on a preview is not an approval of the faults the critics named.

## 4. Anti-patterns (each one happened)
| what I did | what she meant |
|---|---|
| "visual story" -> a framing device | a plot with a protagonist and an arc |
| "eine einzelne Kamerafahrt" -> 68 cut shots | one continuous camera ride; changes through moves and transitions, not cuts |
| "sie flirtet mit der Kamera" -> camera functions around a dancing body | she ADDRESSES the lens: looks, reaches, leans, winks, covers it |
| FIRESTARTER 1:43 -> 10 move codes "only these" | the energy, light and closeness of that clip as the feel of the WHOLE video |
| "mehr Dynamik" -> more effects | more change in camera / pose / rhythm, bolder |
| every note -> a new rule layer for all shots | designed moments; a rule gives every shot the same treatment = generic |
